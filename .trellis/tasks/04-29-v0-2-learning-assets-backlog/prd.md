# v0.2 learning assets backlog

## Goal

Preserve the post-v0.1 learning-asset roadmap without letting it leak into v0.1 implementation tasks.

## Requirements

- Track v0.2 scope as backlog, not current MVP work.
- Include Error Patterns page, mastery tracking, pattern merge/de-dup, rewrite-check, skip/snooze/expire, D+3/D+7 spaced reuse, upgrade opportunities, basic dashboard, and apply-correction revision support.
- Keep v0.1 data shapes compatible where explicitly required by the PRD.
- Do not require v0.2 UI or workflows for v0.1 acceptance.

## Acceptance Criteria

- [ ] v0.2 scope is documented and linked from the MVP parent task.
- [ ] v0.1 tasks explicitly list v0.2 features as out of scope.
- [ ] Future v0.2 work can start from this task without rereading the entire product PRD.

## Definition of Done

- No code implementation is required for this backlog task.
- The backlog remains planning status until v0.1 review value is validated.

## Technical Approach

When v0.2 starts, split this backlog into separate implementation tasks for Error Patterns, rewrite-check/spaced reuse, upgrades/lexicon, dashboard, and apply-correction revisions.

## Out of Scope

- Any v0.2 implementation during v0.1 scaffolding.
- Anki, CET, and Drill Center unless separately prioritized after v0.2.
