## Windows Failure

Maker: Squirrel Windows.

Key log:

```text

```

Interpretation:

* Squirrel uses NuGet metadata.
* The app package needs an author/authors value available to the maker.
* Current `package.json` has no `author`.

## Linux Failure

Step: `Build Linux / Make distributables`

Maker: RPM.

Key log:

```text
error: License field must be present in package: (main package)
```

Interpretation:

* RPM package metadata requires a license.
* Current `package.json` has no `license`.
* Because the package is private, `UNLICENSED` is the conservative npm-compatible value unless the project chooses a public OSS license later.

## Recommended Fix

Add maker-required package metadata in `package.json`:

```json
{
  "author": "lihaoze123",
  "license": "UNLICENSED"
}
```

This is narrower than changing maker config and keeps metadata where Electron Forge makers already expect it.
